**函數設計**:

1. retryWithBackoff 泛型函數：
   - 簽名: `async function retryWithBackoff<T>(operation: () => Promise<T>, options?: RetryOptions): Promise<T>`
   - 支援可選的重試選項（maxRetries、baseDelay、maxDelay、backoffMultiplier）
   - 指數退避計算: delay = min(baseDelay * (backoffMultiplier ^ attempt), maxDelay)
   - 對特定錯誤類型的重試條件判斷

2. RetryOptions 介面定義：
   ```typescript
   interface RetryOptions {
     maxRetries?: number          // 預設 3
     baseDelay?: number           // 預設 100 毫秒
     maxDelay?: number            // 預設 5000 毫秒
     backoffMultiplier?: number   // 預設 2
     shouldRetry?: (error: unknown) => boolean
   }
   ```

3. 具體實現步驟：
   - 逐次嘗試執行 operation
   - 捕捉錯誤時評估 shouldRetry 條件
   - 計算指數退避延遲
   - 使用 setTimeout 等待後重試
   - 最後一次失敗時拋出原始錯誤
   - 完整的 JSDoc 文檔和使用範例

4. 邊界情況處理：
   - maxRetries = 0 時直接執行一次
   - baseDelay、maxDelay 的邊界檢查
   - backoffMultiplier > 1 的驗證
   - shouldRetry 為空時預設重試所有錯誤

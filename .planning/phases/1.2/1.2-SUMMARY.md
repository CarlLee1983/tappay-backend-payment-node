## Code Changes

### Created: src/utils/validators.ts

新模組包含 5 個驗證函數，每個函數都有：
- 完整的 JSDoc 文檔

### Modified: src/TapPayClient.ts

重構了以下 12 個方法，使用驗證函數替代內聯 if 檢查：
1. `validateConfig()` - 配置驗證（3 個檢查）
2. `payByPrime()` - 付款驗證（3 個檢查）
3. `payByToken()` - Token 付款驗證（5 個檢查）
4. `refund()` - 退款驗證（1-2 個檢查）
5. `cancelRefund()` - 取消退款驗證（2 個檢查）
6. `capToday()` - 立即請款驗證（1 個檢查）
7. `cancelCapture()` - 取消請款驗證（1 個檢查）
8. `bindCard()` - 綁定卡片驗證（2 個檢查）
9. `removeCard()` - 移除卡片驗證（2 個檢查）
10. `getTransaction()` - 查詢交易驗證（1 個檢查）
11. `getTradeHistory()` - 查詢歷史驗證（1 個檢查）

### Modified: tests/index.test.ts

添加了新的 describe block 「Validators」，包含：
- 驗證函數進口（排序正確）
- 30 個單元測試（覆蓋正常路徑和錯誤路徑）

- 錯誤訊息驗證

## 驗證邏輯分佈分析

在 `src/TapPayClient.ts` 中已識別 17 處驗證邏輯：

### 驗證模式類型

**類型 1: 字串必填驗證** (9 處)
```typescript
if (!value || value.trim() === '') {
  throw new TapPayValidationError('message', 'field')
}
```
位置: lines 102-108, 260, 269, 312, 316, 376, 417, 421, 542, 581, 585, 660, 694

**類型 2: 數字範圍驗證** (3 處)
```typescript
if (amount === undefined || amount <= 0) {
  throw new TapPayValidationError('message', 'field')
}
```
位置: lines 110-112, 264-266, 320-322, 381-383

**類型 3: 必填欄位驗證（無 trim）** (2 處)
```typescript
if (!value) {
  throw new TapPayValidationError('message', 'field')
}
```
位置: lines 324, 546

**類型 4: 條件式可選欄位驗證** (3 處)
```typescript
if (value !== undefined && value.trim() === '') {
  throw new TapPayValidationError('message', 'field')
}
```
位置: lines 269, 329

### 驗證函數設計

```typescript
// src/utils/validators.ts

// 1. 必填字串驗證
export function validateRequired(
  value: string | undefined,
  fieldName: string
): asserts value is string

// 2. 正數驗證
export function validateAmount(
  amount: number | undefined,
  fieldName: string
): asserts amount is number

// 3. 配置驗證
export function validateConfig(config: TapPayConfig): void

// 4. 可選欄位驗證（允許 undefined，但不允許空字串）
export function validateOptionalField(
  value: string | undefined,
  fieldName: string
): void

// 5. 必填欄位驗證（無 trim，用於 enum/special types）
export function validateRequiredField(
  value: unknown,
  fieldName: string
): void
```

建立新檔案 `src/utils/validators.ts`，包含 5 個驗證函數。每個函數對應一個驗證模式：

1. **validateRequired(value, fieldName)** — 字串必填驗證
   - 檢查 value 不為 undefined/null 且 `trim() !== ''`
   - 拋出 TapPayValidationError
   - 使用 TypeScript assertion 確保類型安全
   - 用於: prime, card_key, card_token, recTradeId, refundId, cardKey, cardToken

   - 檢查 amount !== undefined 且 amount > 0
   - 拋出 TapPayValidationError
   - 用於: amount in payByPrime, payByToken, refund

3. **validateOptionalField(value, fieldName)** — 可選欄位驗證
   - 檢查 value === undefined 或 `trim() !== ''`
   - 不允許空字串，但允許 undefined
   - 拋出 TapPayValidationError
   - 用於: order_number (在 payByPrime, payByToken 中)

4. **validateRequiredField(value, fieldName)** — 通用必填驗證
   - 檢查 value 存在（不支援 trim）
   - 用於: currency（enum 類型）
   - 拋出 TapPayValidationError

5. **validateConfig(config)** — 配置驗證
   - 驗證 partnerKey 和 merchantId
   - 驗證 timeout > 0（如果提供）
   - 用於: TapPayClient constructor
   - 拋出 TapPayConfigError

**實作細節**:
